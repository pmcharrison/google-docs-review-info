PMCH Google Docs review

A personal tool maintained by Peter Harrison for reading and reviewing academic manuscripts in Google Docs.

Document owners choose which documents to share with the review account, pmcharrisonbot@gmail.com. Peter then uses the tool through Codex to read the requested document and, when requested, prepare native suggestions and anchored comments.

The tool requests Google Docs access for documents available to the review account. It also requests per-file Google Drive access to verify the signed-in account. Access remains subject to each document's sharing permissions.

This application is intended for Peter's personal review workflow.
