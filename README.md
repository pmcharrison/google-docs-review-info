# PMCH Google Docs review — public information

Public homepage and privacy information for the PMCH Google Docs review
application, maintained by Peter Harrison for Peter and a limited group of
CMS collaborators. Each operator uses their own account and local token;
the published application registration is shared. This repository contains
static information pages only.

- Homepage: https://pmcharrison.github.io/google-docs-review-info/
- Privacy: https://pmcharrison.github.io/google-docs-review-info/privacy.html

The reusable setup procedure and bundled helper are distributed in
`cms-cambridge/cms-brain`, under `skills/connect-google-docs/`. The original
tool development checkout is separate. Desktop client configuration is
supplied privately; credentials, manuscript snapshots and review receipts
do not belong in this public repository or a skill bundle.

GitHub Pages serves the main branch from the repository root. Update these
pages when the configured review workflow or its handling of data changes.
