Privacy information

PMCH Google Docs review is a personal manuscript-review tool maintained by Peter Harrison. This page describes the configured workflow as of 6 October 2026.

Information accessed and its purpose

The tool reads the authenticated Google account's email address and display name to verify the reviewer identity. For documents Peter requests, it reads document text, formatting, tabs, comments, suggestions and revision information. When authorized by Peter, it submits suggested edits and anchored comments to the original Google Doc.

The Google Docs permission allows access to Google Docs available to the review account, including documents shared with it. A separate per-file Google Drive permission supports account verification. The tool does not automatically read every accessible document.

Processing and storage

OAuth credentials are stored in local files outside the source repository with owner-only file permissions. Document snapshots, proposed changes and submission receipts can contain manuscript content and are stored locally in directories excluded from Git. Local copies remain until deleted by the operator.

Content read or reviewed through Codex is also processed by OpenAI under the applicable account settings and service terms. Google processes API requests and stores any suggestions and comments in the source document. This local tool does not sell Google user data, use it for advertising, or train machine-learning models.

Control and removal

Document owners can remove the review account's sharing permission. The account holder can revoke the application's OAuth authorization in Google Account settings. Revocation stops future API access; it does not automatically delete previously saved local copies, conversation content, or comments and suggestions already submitted to Google Docs.

For questions or requests concerning locally stored review material, contact pmcharrisonbot@gmail.com.
