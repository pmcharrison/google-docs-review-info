Privacy information

PMCH Google Docs review is a local manuscript-review tool maintained by Peter Harrison for Peter and a limited group of Cambridge Centre for Music and Science collaborators. This page describes the workflow as of 7 October 2026. Each operator authorizes the shared application using their own Google account and runs the helper locally.

Information accessed and its purpose

The tool reads the authenticated Google account's email address and display name to verify the reviewer identity. For documents the operator requests, it reads document text, formatting, tabs, comments, suggestions and revision information. When authorized by the operator, it submits suggested edits and anchored comments to the original Google Doc, subject to that account's document permissions.

The Google Docs permission allows access to Google Docs available to the review account, including documents shared with it. A separate per-file Google Drive permission supports account verification. The tool does not automatically read every accessible document.

Processing and storage

Each operator generates their own OAuth access and refresh tokens through individual Google consent. Tokens are stored on that operator's computer in local files outside the source repository with owner-only file permissions. The shared Desktop client configuration is supplied privately and identifies the application; it does not grant access to another operator's account. Document snapshots, proposed changes and submission receipts can contain manuscript content and are stored locally in private scratch directories or directories excluded from Git. Local copies remain until deleted by the operator.

The helper does not send tokens or manuscript snapshots to a central CMS review server. Maintaining the OAuth registration alone does not give the maintainer or other operators access to documents or local tokens. If an operator chooses to send material for support, that is a separate disclosure; avoid sending tokens or confidential manuscript content.

Document content provided to an agent may also be processed by that agent's model provider. For example, Codex uses OpenAI; other agent clients may use other providers. Provider processing, retention and any use of submitted content depend on the chosen service, terms and account settings. Each operator is responsible for choosing settings and a provider appropriate for the documents they review. Local execution of this helper does not mean the agent's model runs locally.

Google processes API requests and stores any suggestions and comments in the source document. The helper uses Google user data to perform the document review or changes the operator requests. It does not sell Google user data, use it for advertising, or use it to train machine-learning models. Its use of Google API information must comply with the Google API Services User Data Policy, including applicable Limited Use requirements.

Control and removal

Document owners can remove the review account's sharing permission. The account holder can revoke the application's OAuth authorization in Google Account settings. Revocation stops future API access; it does not automatically delete previously saved local copies, conversation content, or comments and suggestions already submitted to Google Docs.

For deletion of locally stored review material, contact the operator who performed the review. Conversation data held by an agent provider is governed by that provider's account controls and terms. For questions about the application, contact pmcharrisonbot@gmail.com; the maintainer does not ordinarily hold other operators' local review material.
